## Lightweight runtime and measured performance

No runtime dependencies were added. The production harness uses optional standard development tools and a disposable copy of the starter. Benchmarks validate every measured response; session tests also verify all concurrent counter writes persist. Reports record environment, throughput, individual p50/p95/p99 and PHP allocator memory limitations, with no unstable absolute CI timing gates.

In the synthetic eight-client same-cookie public test with 20 ms of work, median latency changed from 164.02 ms to 21.12 ms after lazy startup removed the unnecessary session lock. Actual session-writing requests remained serialized and persistent. See [the saved reports and comparison](benchmarks.md); these separate hosted-runner measurements do not establish general server capacity.

## Upgrade and maintenance

Call `SessionBootstrap::start()` before application/authentication code reads or writes `$_SESSION`; CSRF helpers do it automatically. The unused `Container` API is removed: construct application services and pass dependencies through constructors. Generated views require adding actual forms and `Csrf::input()` explicitly. Custom bootstraps can use `ErrorResponse::fromException()` for consistent 400/413/500 handling.

Keep native types, precise collection contracts and comments explaining constraints. See [contributing](contributing.md), [migration](migration-0.3.0.md), [release notes](release-notes-0.3.0.md) and [AGENTS.md](../AGENTS.md).
